# YUMYULUCK Portfolio

GitHub Pages 静态作品集。保持现有版式、内容和视觉资产，本轮修复首页入口及动效。

直接发布仓库根目录即可，所有资源使用相对路径，兼容 `/YUMYULUCK-Portfolio/` 子路径。无需安装依赖或构建。

## 当前入口

- `index.html`：正式页面声明、移动端 viewport、样式和模块入口。
- `assets/portfolio-app.js`：可读的 React 页面与状态管理。
- `assets/portfolio-data.js`：沿用的项目和服务内容。
- `assets/portfolio.css`：保留的版式与视觉样式，已移除本轮替换的旧动效定义。
- `assets/portfolio-motion.css`：唯一的开场、渐变毛玻璃与滚动动效定义。
- `assets/portfolio-motion.js`：开场、视频交接、滚动与卡片交互控制器。
- `assets/vendor-ui.js`：从仓库原有构建产物提取的 React、ReactDOM 与图标运行时，保留原许可证注释，不依赖 CDN。

旧的 `index-Bp5ji2XJ.js` / `index-CegOVoI5.css` 不再被页面加载，保留用于对照原版。

## 本轮行为

- 进入后留在首页；取消开场结束时自动跳至作品区。
- 页面使用原生滚动、`100svh` 首屏和固定导航。
- 使用原有 1280×720、24fps 的 `hero-reel.mp4`。该素材并非 1080p/4K；没有自动超分或更换作品。
- 毛玻璃由左侧较强逐渐过渡到右侧清晰，移动端减少模糊层。
- 素材与字体就绪后启动统一遮罩揭示；加载超时使用海报继续，最后文字动画完成后开放滚动。
- 下一段视频开始播放并解码出画面后才淡入；淡入完成前，旧视频继续播放。播放失败保留原段的原生循环。
- 页面进入后台或首页离开视口时暂停视频；减少动态效果模式显示静态背景并取消首屏重叠。
- 拖动、触摸、键盘与箭头使用同一个当前项目状态；拖动结束更新编号和高亮，不强制回拉；两端留出居中空间，让第一张和最后一张也能与编号保持一致。
- 项目弹窗固定于视口，打开时锁定背景滚动，并恢复关闭前的焦点。

## 核查

使用 Node.js 运行，无需 `npm install`：

```sh
npm run check
npm test
```

`check` 验证入口引用、模块语法与本地资源路径；测试覆盖拖动、触摸、开场就绪及视频失败回退等控制逻辑。

当前环境未完成真实浏览器视觉验收。推送前仍应在桌面及手机浏览器确认：首屏高度、毛玻璃方向、连续三轮视频切换、卡片拖动与触摸、减少动态效果及弹窗关闭。
